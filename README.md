# PhraseBoost

Windows 向け 定型文入力支援ツール

[![License](https://img.shields.io/badge/License-Custom-blue.svg)](#ライセンス--利用条件)
[![Platform](https://img.shields.io/badge/Platform-Windows%2010%2F11-0078D6.svg)]()
[![Built with](https://img.shields.io/badge/Built%20with-C%23%20%2F%20WPF-512BD4.svg)]()

PhraseBoost は、よく使う定型文をワンアクションで呼び出して入力できる Windows 用デスクトップアプリです。日々の繰り返し入力や、AI への繰り返しの指示出しといった「同じ文章を何度も打ち直す」手間を減らすことを目的に、個人で開発しました。

## 主な機能

### 略語展開(テキストエクスパンダー)

- 登録した略語を入力し、確定キー(Space / Enter / Tab / Esc / →)を押すとその場で定型文へ展開
- 略語が複数一致したときは候補ポップアップを表示し、キーボード(↑ ↓ / Enter / Tab / Esc)やクリックで選択
- 一致が1件のときはポップアップを出さず直接展開するか、確認のため表示するかを設定で切り替え可能
- 日本語入力(IME)の変換中は展開を抑制し、誤展開を防止
- 低レベルキーボードフック + SendInput API による安定した入力・置換処理

### 動的トークン(定型文に埋め込める特殊文字列)

- 日付・時刻の自動挿入: `{DATE}` `{TIME}` `{DATETIME}` `{YEAR}` `{MONTH}` `{DAY}` `{WEEKDAY}` `{SHORTDATE}`
- `{PHRASE:略語}` — ほかの定型文を呼び出して再帰的に展開(最大10段)
- `{IF:条件}…{ELSEIF:条件}…{ELSE}…{ENDIF}` — 時刻・曜日・日付などによる条件分岐(`HOUR` / `MONTH` / `DAY` / `YEAR` / `DOW` と比較演算子に対応、ネスト可)
- `{INPUT}` / `{INPUT:ラベル}` — 展開時に入力ダイアログを表示し、その場で差し込み
- `{CLIP}` — 展開時点のクリップボードの内容を差し込み
- `{CURSOR}` — 展開後にカーソルを置く位置を指定

### 定型文の整理・管理

- 定型文の登録・編集・削除
- フォルダによる分類(フォルダの追加・リネーム・削除)
- タグ・お気に入り・有効/無効の切り替え・説明メモ
- キーワードによる検索・絞り込み
- 一覧から手動で選んで挿入する選択ダイアログ

### クリップボード履歴

- コピーした内容を自動で履歴として記録(保持件数は設定で変更可能)
- よく使う項目のピン留め(上限を超えても保持)
- ダブルクリックで貼り付け、履歴の一括クリア

### データの入出力・配布

- CSV 形式でのインポート / エクスポート
- ZIP 形式での一括バックアップ / 復元
- 独自形式 `.phe` ファイルのインポート、およびダブルクリックで取り込めるファイル関連付け(専用アイコン付き)

### 常駐・システム連携

- タスクトレイ常駐(トレイアイコン + 右クリックメニュー)
- Windows ログイン時の自動起動(オン/オフ切り替え)
- 二重起動を防ぐ単一インスタンス制御
- self-contained 形式の単一実行ファイル(.NET ランタイムの別途インストール不要)

---

## こんな場面で役立ちます

- よく使う文章やテンプレートを素早く挿入したいとき
- AI への定型的な指示文(プロンプト)を繰り返し入力する手間を減らしたいとき
- 住所・署名・定型の説明文など、繰り返し入力する文章を一元管理したいとき

---

## 動作環境

- Windows 10 / 11 (64-bit)
- 実行ファイルは self-contained 形式で配布しているため、.NET ランタイムの別途インストールは不要です

---

## ダウンロード・使い方

1. [Releases](../../releases) ページから最新版の実行ファイル(`PhraseBoost.exe`)をダウンロードします。
2. 任意のフォルダに置いて実行します(インストール作業は不要です)。常駐型のため、起動するとタスクトレイに常駐します。
3. 定型文を登録し、必要なときに呼び出して入力します。

> 本リポジトリではソースコードは公開しておりません。配布しているのはコンパイル済みの実行ファイルのみです。
